# moodle-h5p-xAPI-improvements

H5P – xAPI - Modifications apportées au code de Moodle afin de pouvoir créer des statements xAPI personnalisés, de capturer et modifier ceux qui sont déjà générés par H5P et d’envoyer ces statements vers un LRS. Les modifications du code permettent également de tracer davantage d’actions utilisateur sur les vidéos interactives H5P : la mise en pause de la vidéo, les retours en arrière, le positionnement sur des signets, etc.
